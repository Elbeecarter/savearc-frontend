# 💰 SaveArc — Community-Powered Savings on Arc Network

> Inflation-proof micro-savings for Nigeria and Africa, built on Arc Network with USDC stablecoin

[![Arc Network](https://img.shields.io/badge/Arc-Mainnet-orange)](https://arc.io)
[![Live](https://img.shields.io/badge/Live-savearc.vercel.app-green)](https://savearc.vercel.app)

## 🌍 Overview

SaveArc digitizes Africa's traditional Ajo/Esusu rotating savings groups using smart contracts on Arc Network. Users save in USDC — zero inflation risk.

## ✅ Features

- 💰 **Personal Vaults** — Save in USDC with time-locked goals
- 🤝 **Digital Ajo Pools** — Rotating savings groups with automated payouts
- 📧 **Circle Wallets** — Email login, no MetaMask or seed phrase needed
- 🤖 **AI Savings Agent** — Autonomous USDC deposits every 4 hours
- ⚡ **Arc Mainnet** — Sub-second finality, USDC native gas
